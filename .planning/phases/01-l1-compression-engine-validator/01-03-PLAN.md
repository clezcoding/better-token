## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering / Elevation of Privilege | `cli.ts` path handling | high | mitigate | `path.resolve` + `zod` validation; reject non-markdown/binary (D-19); `fs.realpath` on parent; no shell exec. Interactive prompt only offers detected canonicals — user cannot type an arbitrary path. |
| T-01-09 | Tampering | `--yes` bulk compress | medium | mitigate | Each file still goes through `compressFile` → validator gate + atomic write + sidecar create-if-missing; `--yes` only changes the prompt, not the safety invariants. |
| T-01-10 | Information Disclosure | `validate` on a file with no sidecar | low | accept | `validate` reports `no original to compare; internal check passed` — no file is written, no sidecar is created, no content leaves the local process. |
| T-01-11 | Tampering | Interactive prompt path injection | medium | mitigate | Prompt offers only the detected canonical set; the selected value is one of those absolute paths — never a free-form user string. `zod`-validated before passing to `compressFile`. |
</threat_model>
